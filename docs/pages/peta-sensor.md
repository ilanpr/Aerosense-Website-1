# Peta sensor

Halaman ini menyatukan peta skematis, daftar node, dan panel detail untuk membaca kondisi tiap lokasi.

## Isi halaman

Sepuluh node contoh mewakili titik di kawasan Gresik dan sekitarnya. Tabel menampilkan ID, AQI, PM2.5, status, dan waktu pembacaan yang terlihat. Panel detail memuat AQI, PM2.5, eCO2, TVOC, serta suhu node aktif.

## Interaksi

- Pilih penanda pada peta atau nama di tabel untuk mengganti panel detail.
- Gunakan filter status untuk menampilkan semua node, node baik, atau node yang perlu perhatian.
- Jumlah node yang terlihat mengikuti filter.
- Penanda node yang tidak sesuai filter disembunyikan dari peta.

Peta dibuat sebagai ilustrasi wilayah. Posisi penanda belum berasal dari koordinat perangkat sensor.
