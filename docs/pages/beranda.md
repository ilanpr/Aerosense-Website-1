# Beranda

Beranda memberi gambaran awal sebelum pengguna membuka data yang lebih rinci.

## Isi halaman

Panel utama menampilkan AQI rata-rata kawasan dan kategori udara. Tiga kartu di bawahnya merangkum PM2.5, estimasi eCO2, dan jumlah node aktif. Peta ringkas menampilkan beberapa titik sensor; setiap titik dapat membawa pengguna ke halaman Peta sensor. Di sisi kanan ada saran harian AERO-BOT dan dua peringatan terbaru.

## Interaksi

- `Lihat peta sensor` dan `Lihat semua node` membuka halaman peta.
- Titik pada peta ringkas membuka detail node yang dipilih.
- `Saran lain` mengganti teks rekomendasi dari daftar lokal.
- Tautan peringatan membuka halaman Peringatan.
- `Tanya AERO-BOT` membuka halaman percakapan.

Nilai pada kartu dan peta masih data contoh. Kategori dan angka tidak berubah dari waktu ke waktu.
